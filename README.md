# Portal GEIRA - Grupo de Educação Inclusiva da Região Amazônica

Este é o repositório do portal web oficial do **GEIRA**, um grupo de pesquisa acadêmica focado em educação especial inclusiva na Amazônia. O site foi desenvolvido com foco em acessibilidade absoluta, design lúdico e funcionalidade para pesquisadores, bolsistas e a comunidade em geral.

## 🚀 Tecnologias Utilizadas

- **Frontend:** React + Vite
- **Linguagem:** TypeScript
- **Estilização:** Vanilla CSS
- **Roteamento:** React Router DOM v6
- **Acessibilidade:** VLibras, Modos de Alto Contraste e Escalonamento de Fonte.

## 📂 Estrutura do Projeto

- `/src/pages`: Contém as páginas principais (Home, Projetos/Personagens, Eventos/Diretrizes, Login, Dashboards).
- `/src/components`: Componentes reutilizáveis como o VLibras e barras de acessibilidade.
- `/public/Imagens`: Ativos visuais do projeto, incluindo os mascotes e elementos de design amazônico.

## 🛠️ Como Executar Localmente

1. Clone o repositório (ou baixe os arquivos).
2. No terminal, acesse a pasta do projeto.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse `http://localhost:5173` no seu navegador.

## ♿ Acessibilidade

O portal GEIRA implementa:
- **VLibras:** Tradução automática para a Língua Brasileira de Sinais.
- **Alto Contraste:** Otimização visual para usuários com baixa visão.
- **Ajuste de Fonte:** Controle dinâmico do tamanho dos textos.
- **Navegação Semântica:** Estrutura preparada para leitores de tela.
